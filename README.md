# ТиМП — лабораторная работа №1

- `Task1_AlphaCipher` — шифр Виженера для русского алфавита (задание 2.1)
- `Task2_BetaCipher` — шифр табличной маршрутной перестановки (задание 2.2)

## Сборка и запуск
Нужны `g++` и `make` (`sudo apt install build-essential`).

```bash
make           # собрать оба проекта в bin/
make run1      # собрать и запустить задание 1
make run2      # собрать и запустить задание 2
make clean     # удалить bin/ и obj/
```

Русская локаль (желательно): `sudo locale-gen ru_RU.UTF-8`.
Если её нет, программа переключится на C.UTF-8.
